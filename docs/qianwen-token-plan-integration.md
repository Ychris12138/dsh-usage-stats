# 千问 Token Plan 接入状态（开发中）

2026-11-12 已使用个人版账户验证官方 CLI 同一授权与额度查询链路：设备授权成功，使用授权令牌获取专用查询令牌，读取订阅、额度配置及月度使用比例；未安装 CLI。随后在隔离的 DSH Web 实例中完成授权、凭据持久化、真实账户卡片显示，并在重启后再次查询成功。隔离实例的本机凭据文件权限为 `0600`。

`lib/qianwen-token-plan.js` 提供授权会话和只读查询；DSH 界面提供显式授权入口，账户服务使用独立的管理凭据引用。协议参考千问官方 CLI 源码；其接口虽然由官方客户端使用，但不应据此声称已经是面向所有第三方应用的稳定公开契约。个人版月度及旧版周度窗口按返回字段识别，缺失或异常不显示为零。订阅总 Credits 是档位额度，不代表精确剩余额度或加油包。

2026-11-12 已在当前 Desktop 识别到 `qwen-token-plan-cn` 模型路由，并使用 Desktop 0.2.2-rc.1 自带运行时启动独立的 Web profile：该路由使用独立管理授权而非模型 API Key，真实个人版额度查询成功。此测试复用本机隔离测试授权；对运行中 Desktop 宿主的桥接与外链处理仅做代码检查，没有修改其 profile 或重启窗口。

## 尚未完成

- 真实验收仅覆盖一个个人版账户的 DSH Web 和 Desktop 自带运行时的独立 Web profile，Desktop 原生窗口未做真实界面验收。需测试不同用户的个人套餐、无订阅和到期状态，以及加油包与累计用量的口径。团队版和国际版不在当前实现中。
