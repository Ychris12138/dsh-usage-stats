# v0.3.7

本版整合 0.3.6 发布后的计量、账户与界面改进。

## 计量与排行

- 修复新版 DSH seeded/fork 会话的重复计量：读取精确继承边界，并在仍存的副本间匹配用量证据。普通 fork 无需 parentSession；父日志缺失或只剩部分历史时保留唯一副本。保留 #153 原作者提交，并通过 #154 完成补充修复。
- 计入 `compaction/summary` 的模型用量；压缩摘要与 assistant usage 交错、同一摘要修正及重启后增量更新不再重复累加。
- 空读取、失败的全量重折叠保留已有账本；缓存迁移后的待重折叠状态在重启后继续有效。
- 新增供应商分组与组内模型 Token 用量排行，可查看所选月份或全部记录。独立路由（例如两个 Z.ai 账号）保持分开。

## 账户与界面

- 新增显式配置、默认不启用的火山方舟个人 Coding Plan CLI 实验适配器（#143）。仅读取个人套餐百分比与重置时间；尚无真实账户对账，#74 继续保留验收。
- 新增默认关闭的“跟随当前会话”（#152 / #158）：按确认的主视图完整 route id 选择卡片，手动选择立即退出，保留最后手动偏好；旧宿主缺少能力时降级手动模式。

- OpenCode Go 优先解析当前 `OPENCODE_API_KEY`，使用新版 usage 路径；旧路径只在明确不支持新路径时回退。显式账户配置不会借用其他账户凭据。
- OpenCode Go 侧栏明确显示月剩余；短窗口仍独立触发额度提醒。月窗口缺失、无效或重复时省略数值。
- 声明式 monitor 支持受约束的 query-key 鉴权；响应反射凭据时拒绝缓存与展示。
- 提高浮动面板层级，适配移动端扩展；补齐 Hub 渠道显示简称，并保护独立 API 路由的账户归属。

## 升级和限制

缓存 schema 升级至 10。生产升级前请备份 `$DSH_HOME/storages/usage-stats-cache.json`；正常升级会迁移既有汇总并重折叠可读日志。旧宿主缺少精确继承边界时继续保留原有计量，仍可能重复。不可读旧聚合没有足够样本证据，不能保证校正其历史；降级到旧插件可能需要从仍可读取的源日志重建。新缓存保留脱敏的逐样本证据，占用可能增加。

自动化用例验证计量、迁移与安全边界；排行组件完成合成数据的宽窄布局检查。这不代表真实账户账单或安装后 DSH 的完整对账。费用仍是估算。

以下内容未作为本版已完成能力：

- #133：宿主尚无搜索响应 token usage 事件。
- #74：实验 Ark 适配已纳入，但真实个人订阅验收仍未完成。
- Hub 官方 `2.9.261029` 仍不提供 `creditBalance` 服务；历史配套补丁是实验材料，不能用于证明当前官方包支持。
- #140：OpenCode 真实账户验收仍待确认。

## 重新冻结（2026-10-30）

本次按用户要求纳入 #143 和 #152。此前 0.3.7 候选安装包已作废；应使用新的最终目录、冻结源码与校验清单，不能混用旧候选。16 组自动化测试覆盖实验 Ark 和跟随控制器；合成账户行为验证不等于真实额度对账。

## 发布顺序

先冻结并校验安装包，由维护者发布该精确 npm tarball；核对线上字节和 integrity 后再将发布提交合入 main、更新市场目录、打 tag 并公开 GitHub Release。发布准备分支和 draft release 不表示 npm 已发布。
